# 阿里云安全组配置指南

## ⚠️ 重要：必须配置安全组才能从外网访问

您的应用需要在阿里云控制台开放以下端口：

## 🔧 配置步骤

### 1. 登录阿里云控制台
https://ecs.console.aliyun.com/

### 2. 找到您的 ECS 实例
- 服务器 IP: 139.224.245.244
- 点击实例名称进入详情页

### 3. 配置安全组规则

点击 **安全组** -> **配置规则** -> **入方向** -> **手动添加**

添加以下规则：

#### 规则 1: API HTTP 端口
- **授权策略**: 允许
- **优先级**: 1
- **协议类型**: 自定义 TCP
- **端口范围**: 5000/5000
- **授权对象**: 0.0.0.0/0
- **描述**: GLXT API HTTP 端口

#### 规则 2: HTTP（如果配置 Nginx）
- **授权策略**: 允许
- **优先级**: 1
- **协议类型**: HTTP(80)
- **端口范围**: 80/80
- **授权对象**: 0.0.0.0/0
- **描述**: HTTP 端口

#### 规则 3: HTTPS（如果配置 SSL）
- **授权策略**: 允许
- **优先级**: 1
- **协议类型**: HTTPS(443)
- **端口范围**: 443/443
- **授权对象**: 0.0.0.0/0
- **描述**: HTTPS 端口

#### 规则 4: SQL Server（⚠️ 仅开发调试，生产环境不要开放）
- **授权策略**: 允许
- **优先级**: 100
- **协议类型**: 自定义 TCP
- **端口范围**: 1433/1433
- **授权对象**: 您的本地 IP（不要用 0.0.0.0/0）
- **描述**: SQL Server 端口（仅开发）

### 4. 保存配置

点击 **保存** 后，规则立即生效（无需重启服务器）。

## ✅ 验证配置

在本地电脑运行：

```powershell
# 测试端口是否开放
Test-NetConnection -ComputerName 139.224.245.244 -Port 5000

# 或使用 curl
curl http://139.224.245.244:5000/health
```

## 🔐 安全建议

### 生产环境：
- ✅ 开放: 80 (HTTP), 443 (HTTPS), 5000 (API)
- ❌ 关闭: 1433 (SQL Server) - 只允许容器内部访问

### 开发环境：
- 可以临时开放 1433，但授权对象设置为您的 IP，不要用 0.0.0.0/0

## 🔍 排查安全组问题

如果配置后仍无法访问：

1. **检查安全组是否生效**
   - 确认规则已保存
   - 优先级不要设置太低

2. **检查实例是否关联了正确的安全组**
   - ECS 实例详情 -> 安全组 -> 查看已关联的安全组

3. **检查服务器内部防火墙**
   ```bash
   # SSH 登录服务器后运行
   sudo firewall-cmd --list-all
   ```
